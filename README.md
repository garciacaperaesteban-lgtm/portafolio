## Funcionalidades JavaScript

Para este portafolio elegí agregar interactividad con JavaScript enfocándome en 
mejorar la experiencia de usuario sin complicar el diseño original. Estas son las 
funcionalidades que implementé y por qué:

### 1. Modo oscuro
Elegí esta funcionalidad porque hoy en día es un estándar en la mayoría de sitios 
web modernos. Además de dar una opción visual más cómoda para quienes navegan de 
noche o prefieren fondos oscuros, guarda la preferencia del usuario con 
`localStorage`, así que si vuelve a visitar la página, el modo se mantiene activado.

### 2. Mensaje interactivo al hacer clic (botón "Saludar")
Incluí esta funcionalidad como un detalle simple de interactividad para practicar 
manipulación del DOM (creación de elementos, mostrar y ocultar contenido). También 
sirve como un pequeño gesto de bienvenida para quien visita el portafolio.

En general, prioricé funcionalidades que fueran fáciles de implementar pero que 
aportaran valor real en usabilidad y experiencia de usuario, evitando agregar 
efectos innecesarios que no tuvieran un propósito claro.
